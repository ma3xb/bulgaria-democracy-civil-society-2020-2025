# Democracy and Civil Society in Bulgaria, 2020–2025

A bilingual interactive presentation of publicly documented programmes, funds and projects supporting democratic development, human rights and civil society in Bulgaria.

## Live presentation

[Open the GitHub Pages site](https://ma3xb.github.io/bulgaria-democracy-civil-society-2020-2025/)

The presentation is available in Bulgarian and English. Its figures are based on public sources and should be verified against official records when used for audit, policy or in-depth analysis.

## Structure

- `dist/index.html` — presentation markup
- `dist/styles.css` — visual design and responsive layout
- `dist/app.js` — bilingual content, project data, filters and visualisations

The `gh-pages` branch contains the deployable contents of `dist` at its root.
